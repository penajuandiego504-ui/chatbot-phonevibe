# Chatbot PhoneVibe

## Descripción

PhoneVibe es un chatbot creado para ayudar a los clientes de una tienda de celulares. El chatbot permite consultar información sobre los productos y sus precios.

## ¿Cómo funciona?

El chatbot recibe una pregunta escrita por el usuario y analiza las palabras de la pregunta para identificar qué información está buscando. Después muestra una respuesta relacionada con los celulares disponibles.

## Productos disponibles

- Samsung Galaxy A05s — $650.000
- iPhone 17 — $2.500.000
- Xiaomi Redmi Note 12 Pro 4G — $900.000
- Motorola Moto G14 — $800.000

## Funciones

El chatbot puede:

- Mostrar el precio de los celulares.
- Informar cuáles son los productos disponibles.
- Indicar cuál es el celular más barato.
- Indicar cuál es el celular más caro.
- Responder un saludo.
- Finalizar la conversación escribiendo "salir".

## Tecnología utilizada

- Python
- Google Colab
- GitHub

## Ejemplos

**Usuario:** ¿Cuánto cuesta el iPhone 17?

**Chatbot:** El iPhone 17 tiene un precio de $2.500.000.

**Usuario:** ¿Cuál es el más barato?

**Chatbot:** El celular más barato es el Samsung Galaxy A05s, con un precio de $650.000.
